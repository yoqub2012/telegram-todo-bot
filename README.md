# 📋 Telegram To-Do List Bot

A simple and powerful To-Do List bot for Telegram, built with Python.

## ✨ Features
- ➕ Add tasks
- 📋 View all tasks
- ✅ Mark tasks as done
- ❌ Delete specific tasks
- 🗑 Clear all tasks

## 🛠 Installation

\```bash
pip install pyTelegramBotAPI
\```

## 🚀 Usage

1. Get your token from @BotFather
2. Replace `YOUR_BOT_TOKEN_HERE` with your token
3. Run the bot:

\```bash
python todo_bot.py
\```
